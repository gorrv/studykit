Why these are worth doing
The machines, words, expressions and splits are different every time, and your answer is checked by running the same simulator the tools upstairs use — the DFA question is marked by actually running the DFA. You cannot pass by half-remembering a question you have seen before; you have to do the working.

If you get one wrong
Every explanation shows the working — the full configuration sequence for a DFA question, the surviving split for a pumping one, the tape for a Turing machine. Read it, then draw another on the same topic and do that one by hand before pressing Check.
