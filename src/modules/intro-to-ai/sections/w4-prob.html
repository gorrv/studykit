Expected Utility

turning a spread of possible outcomes into one number
The job of this page
Part 2 ended with a problem. An action no longer has an outcome, so it no longer has a value — and if actions have no values, you cannot compare them. This page builds the one number that lets you compare them. It is called an expected value, and you already know how to compute one.

Expected value, with a coin

The idea

I flip a fair coin. Heads pays you £5, tails pays £0. What is a flip worth?

Not £5 — you only get that half the time. Not £0 either. The honest answer is what you would average if you did it many times:

(0.5 × £5) + (0.5 × £0) = £2.50

£2.50 is not a possible outcome of a single flip. It is still the right number to make decisions with — if someone charged £2 a flip you should play, and at £3 you should not.

The recipe, and it never changes
expected value = Σoutcomes (probability of it) × (value of it)

For each thing that could happen, multiply how likely it is by what it is worth. Add those up. That is all an expectation ever is, in any subject.

The Σ (sigma) just means "add up the following, once for each outcome". E[X] is the standard shorthand for "the expected value of X".

The vertical bar is read "given". It is not division. P(s′ | s, a) is just "the chance of ending at s′, given you were at s and did a" — the transition model from Part 2, written the standard way.

A check worth doing on every exam question
Add up the probabilities of an action's outcomes. If they do not come to 1, you have missed an outcome — usually a slip that bumps a wall and leaves you where you started. That single check catches most arithmetic slips in these questions.

The expected utility of an action

The coin formula, with the names changed
E[U | s, a]  =  Σs′ P(s′ | s, a) · U(s′)

In words: for each square you might land on, multiply the chance of landing there by what that square is worth. Add them up. That is what taking action a from square s is worth.

how likely each is0.5 each0.8, 0.1, 0.1
what each is worth£5 or £0U(s′), the utility of that square

It is literally the same sum. If you can price a coin flip you can price an action.

The one genuine difference — and it is the reason for Part 4
With the coin, you were told that heads is worth £5. On the grid, nobody tells you what U(s′) is.

A square's worth depends on where you can get to from it, which depends on what those squares are worth, which depends back on the first one. The definition is circular.

So you cannot just look the numbers up. You have to compute them, and the way to break the circle is to guess and repeat. That is value iteration, and it is Part 4.

Exam-style takeaways

What to have ready
  • Expected value = Σ (probability × value), over everything that could happen. Same formula for coins and for actions.
  • E[U | s, a] = Σs′ P(s′ | s, a) · U(s′) — the value of taking action a from square s.
  • P(A | B) is read "A given B", and the bar is not division.
  • Probabilities of an action's outcomes must sum to 1 — use it as a check. Missing outcome is usually a wall bump.
  • Every action has three outcomes here: 0.8 intended, 0.1 each side. Never backwards.
  • U(s′) is not given to you. Its definition is circular, and value iteration exists to break the circle.
  • An expected value need not be a possible outcome — £2.50 is not a coin result, and it is still the right number to decide with.
