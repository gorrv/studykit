Three neighbours that are easy to confuse

Admissible = never overestimates the true remaining cost, i.e. h(n) ≤ h*(n) for every n. A straight line can never be longer than a road, which is why the ruler heuristic is admissible by construction. Admissibility is what makes A* optimal — lose it and A* can return a worse path.

h = 0 everywhere is admissible (and turns A* into UCS). A more informed heuristic is one that is larger while still admissible — it expands fewer nodes.

Adversarial search

Definitions
  • Minimax value — the value of a node assuming both players play optimally: MAX takes the max of its children, MIN the min.
  • Ply — one move by one player. A “two-ply” lookahead is one move each.
  • Evaluation function — a heuristic estimate of a state's value, used when you cut off before a terminal state.
  • α — the best value MAX can already guarantee on the path so far. Only ever increases.
  • β — the best value MIN can already guarantee. Only ever decreases.
  • The cut rule — prune when β ≤ α.

Alpha-beta returns exactly the same value as minimax — it is a pruning optimisation, never an approximation. With perfect move ordering it can search roughly twice as deep in the same time.

Constraint satisfaction

The definitions
  • CSP — a set of variables, a domain of values for each, and constraints.
  • A constraint = a scope (which variables it involves) + a relation (which combinations are legal).
  • Solution — a complete and consistent assignment.
  • Constraint graph — variables are nodes, constraints are edges.
  • Arc consistency — X→Y is consistent when every value in X's domain has some legal partner in Y's.

Unlike Topic 01 search, the path is irrelevant — only the final assignment is the answer.

Planning

The vocabulary
  • Closed-world assumption — anything not stated in the state is false. This is why you only list what is true.
  • Action schema — parameters, precondition, effect (add list and delete list).
  • Fluent — a numeric quantity that actions change, as opposed to a boolean predicate.
  • Durative action — has a duration, with conditions at start, over all, at end.
  • Forward chaining — search forward from the initial state, applying applicable actions. It is A* with a planning heuristic.
  • Relaxation — solve an easier problem and use its cost as h. The RPG's relaxation is ignore all delete effects.

The RPG heuristic is h = Σ|Oi|, the total number of actions in the extracted relaxed plan. Because deletes are ignored, fact layers only ever grow, so the graph reaches a fixpoint.

MDPs and value iteration

The pieces
  • Transition model P(s′ | s, a) — where you actually end up. Markov = it depends only on the current state, not the history.
  • Policy π(s) — an action for every state. Stochastic worlds need a policy, not a plan.
  • Discount factor γ — how much a future reward is worth now. γ < 1 keeps infinite sums finite.
  • Bellman update — U(s) ← R(s) + γ·maxa Σs′ P(s′|s,a)·U(s′).
  • Value iteration — apply the Bellman update to every state, repeatedly, until it stops changing.
  • Policy extraction — once U has converged, π(s) = the arg max of that same expression.

Stopping rule: iterate until the largest change δ satisfies δ < ε(1 − γ)/γ.

The reward function is the specification. Topic 01's value alignment problem, in numbers — set R too negative and the optimal policy is to die quickly.

Train / validation / test — and why validation exists
  • Training set — fits the parameters.
  • Validation set — chooses between models (degree, K, hyperparameters).
  • Test set — used once, to report performance.

Selecting on the test set makes it a training set, and the number you report stops meaning anything. That is the whole reason there are three.

Clustering

K-means and hierarchical
  • K-means — pick K initial centres; assign each point to the nearest centre (ties to the lowest index); recompute each centre as the mean of its points; repeat until the clusters stop changing.
  • Within-cluster variance — the quality measure; lower total is better.
  • K-means finds a local optimum only — a different initialisation can give a different, worse answer.
  • Hierarchical — start with every point its own cluster, repeatedly merge the two closest, until one remains.
  • Dendogram — the merge tree; cut it at a height to choose K. A tall vertical gap is a good place to cut.
Linkage — the distinction that gets examined
LinkageDistance between clustersGuarantees
Singlethe closest pairconnectivity — chains of short hops; prone to chaining
Completethe furthest pairbounds the cluster's diameter — every pair is within the threshold
Averagethe mean over all cross pairscompromise; guarantees nothing about the worst pair

L1 (Manhattan) = Σ|differences|; L2 (Euclidean) = √(Σ differences²). L2 ≤ L1 always — a free sanity check.

Regression and decision trees

Linear regression
  • ŷ = β₀ + β₁x; the residual is ε = y − ŷ; we minimise SSE = Σε².
  • “Linear” refers to the parameters β, not the variables x — so polynomial regression is a special case of linear regression.
  • Theorem 7.3 gives a closed form from five numbers: n, Σx, Σy, Σx², Σxy. Rare in ML — most methods cannot be proved optimal.
  • Normality of the errors is not used in that proof, only for further properties of the estimators.
  • At the optimum the residuals sum to zero — the cheapest possible check on an answer.
Decision trees
  • Gini(v) = Σ pᵢ(1 − pᵢ), equivalently 1 − Σpᵢ². Zero ⟺ pure; maximum 1 − 1/k when all classes are equal.
  • Gini-Split(A) = Σⱼ (nⱼ/n)·Gini(vⱼ) — a weighted average over the children.
  • Choose by arg min, at every node, not just the root. Different branches may split on different features.
  • Node label = majority class, ties to the lowest index; class order is alphabetical.
  • Left branch = True in a binary tree; label the arrows in a non-binary one.

Reinforcement learning

The two quantities
q⋆(a)Qt(a)
Isthe true expected reward, E[Rt | At = a]your estimate of it
Known to the agent?neveryes — it is built from experience
Changes over time?no (stationary assumption)yes, that is the point

Qt(a) averages the rewards a paid on steps strictly before t. Q₁(a) = 0, and 0 whenever the action has never been taken.

The three selection methods
MethodRuleTie-break
RandomPr(At = aᵢ) = 1/k—
Greedyarg maxa Qt(a), with Q₁ = 0randomise among the maxima
ε-greedyrandom with probability ε, greedy with probability 1 − εas greedy
UCBarg maxa [ Qt(a) + c√(ln t / Nt(a)) ]lowest index

The two tie rules are different — greedy randomises, UCB takes the lowest index. And Pr(greedy action) = 1 − ε + ε/k, not 1 − ε, because the random branch can reach it too.

ε = 0 gives greedy; ε = 1 gives random. In UCB, N = 0 counts as +∞, so the first k steps are forced, and c = 0 collapses UCB into greedy.

Bandits vs MDPs — the two differences
  • The reward function is unknown and must be estimated.
  • There is only one state — whichever action you take you return to the same choice. Richer RL estimates q⋆(s, a) per state-action pair.

Allocative harms are about who gets things (opportunities, resources, quality-of-service); representational harms are about how people are portrayed (stereotyping, demeaning, erasing, alienating, loss of self-identification, essentialist categories).

Direct discrimination = disparate treatment (because of an attribute); indirect = disparate impact (despite the attribute not being used). Removing the attribute stops the first and not the second.

Threads that run through the whole module
  • Everything is search. Minimax is a DFS. Backtracking is a DFS. Forward chaining is A*. Only the state and the successor rule change.
  • Relaxation is the general recipe for a heuristic. Straight-line distance (W1) and “ignore delete effects” (W3) are the same trick.
  • Fail first, cheaply. Alpha-beta's β ≤ α, forward checking's empty domain and MRV are all the same move.
  • When the world stops cooperating the answer changes shape. Deterministic ⇒ a plan. Stochastic ⇒ a policy. Adversarial ⇒ a strategy assuming the worst. Unknown rewards ⇒ exploration.
  • Guarantees give way to measurement. A*, alpha-beta, AC-3 and value iteration come with proofs; machine learning substitutes held-out evaluation.
  • The objective is the specification. The MDP reward function, the regression loss, the fairness function — each one is somebody deciding what “good” means.
