Why this section exists
Chapter 7 poses five exercises and prints an empty Solution to Exercise n box after each one. Every answer below has been worked from the definitions and independently re-computed in exact arithmetic, so the fractions are exact rather than rounded. Attempt each one before reading on — these are close to the shape of an exam question.
Exercise 1

Estimate the value of x = 5 using the regression line from the values in Table 7.1.

The line was found in §7.2.2 to be ŷ = −(4/7)x + 6/7. Prediction is one substitution:

ŷ(5) = −(4/7)·5 + 6/7 = −20/7 + 6/7 = −14/7
answerŷ(5) = −2, exactly. Table 7.1's missing entry is −2.
Worth noticing
x = 5 is well outside the range of the data, which runs from −1 to 2. The arithmetic is trivial; the honest caveat is that this is extrapolation, and a linear model has nothing to say about whether the straight-line relationship survives out there. If a question asks you to comment, that is the comment.
Exercise 2

Find the best fit line for the dataset that is the same as this one but changing the last point to (2, 1), instead of (2, 0).

Data: (−1, 2), (0, 0), (2, 1). Doing it the notes' way — residuals first:

ε₁² = (2 − β₀ + β₁)²   ε₂² = (0 − β₀)²   ε₃² = (1 − β₀ − 2β₁)²

Expanding and collecting:

SSE = 3β₀² + 5β₁² + 2β₀β₁ − 6β₀ + 0·β₁ + 5

The β₁ term has vanished, because Σxᵢyᵢ = (−1)(2) + 0 + (2)(1) = 0. Reading the two vertices at −b/2a:

β̂₀ = (6 − 2β₁)/6     β̂₁ = −2β₀/10 = −β₀/5
30β₀ = 30 + 2β₀  ⟹  28β₀ = 30

Or straight from Theorem 7.3 with n = 3, Σx = 1, Σy = 3, Σx² = 5, Σxy = 0, denominator 3·5 − 1² = 14:

β̂₁ = (3·0 − 1·3)/14 = −3/14    β̂₀ = (5·3 − 1·0)/14 = 15/14
answer β̂₀ = 15/14 ≈ 1.0714 and β̂₁ = −3/14 ≈ −0.2143, so
ŷ = −(3/14)x + 15/14

SSE at the optimum is 25/14 ≈ 1.7857.

What moving one point by one unit did
The slope went from −4/7 = −8/14 to −3/14 — flattened to just over a third of its former steepness — and the intercept rose from 6/7 to 15/14. With only three points, every one of them is high leverage. That is the whole reason Week 5 spent time on outliers and MSE.

n = 4, so the shared denominator is n·Σx² − (Σx)² = 4·14 − 4² = 40.

β̂₁ = (4·(−21) − 4·(−4)) / 40 = (−84 + 16)/40 = −68/40 = −17/10
β̂₀ = (14·(−4) − 4·(−21)) / 40 = (−56 + 84)/40 = 28/40 = 7/10
answer β̂₀ = 0.7 and β̂₁ = −1.7, so ŷ = −1.7x + 0.7. SSE at the optimum is 21.1.
Check it before you move on
Predictions are 2.4, 0.7, −2.7, −4.4; residuals are −0.4, −0.7, 3.7, −2.6. They sum to 0. Any answer whose residuals do not cancel is arithmetically wrong, and this check costs one line.

Also note how much worse the fit is than in Exercises 1–2: SSE 21.1 against 1.79. And look where the error ends up. The squared residuals are 0.16, 0.49, 13.69 and 6.76 — the biggest by far belongs to (2, 1), not to the obviously odd (3, −7). Squared error pulls the line so hard towards the extreme point that a perfectly ordinary point becomes the worst-fitted one, contributing 65% of the total. That is outlier sensitivity doing real damage, and it is the argument for Least Absolute Deviations in a sentence.

Exercise 4

For a vector with two dimensions (k = 2), what is the maximum possible Gini(v)?

With k = 2, write p₁ = p, so p₂ = 1 − p. Definition 7.4 gives

Gini(v) = p(1 − p) + (1 − p)p = 2p(1 − p) = 2p − 2p²

A downward parabola in p. Its vertex is at p = −b/2a = −2/(2·(−2)) = ½, and there

Gini = 2·(½)·(½) = ½
answer The maximum is ½, reached when the two classes are exactly balanced — v = (m, m) for any m. The minimum is 0, at p = 0 or p = 1, i.e. a pure node.
The general result, which is what a follow-up would ask
For k classes, Gini = 1 − Σpᵢ², and Σpᵢ² is minimised subject to Σpᵢ = 1 when every pᵢ = 1/k. So
max Gini = 1 − k·(1/k)² = 1 − 1/k
k = 2 → ½, k = 3 → ⅔ ≈ 0.667, k = 4 → ¾. Note that the root of Figure 7.5 sits at 0.658 against a ceiling of 0.667 — that node is very nearly as impure as three classes can be, which is why any split at all looks like an improvement.
Exercise 5

Refer to the toy dataset in Table 7.4 — 20 data points, 3 binary features, 4 classes. Which of the 3 attributes should we start splitting the tree by, and what are the three Gini-Split values involved?

Classes in alphabetical order A, B, C, D. The 20 rows give A 6, B 5, C 5, D 4, so the root is [6, 5, 5, 4] and

Gini(root) = (6·14 + 5·15 + 5·15 + 4·16)/20² = 298/400 = 0.745

Now split by each feature in turn. Every feature is binary and — conveniently — splits 10/10, 9/11 and 10/10, so the weights are easy.

splitrowsvalue [A,B,C,D]Gini of that child
Feature1 = 010[4, 2, 4, 0]0.24 + 0.16 + 0.24 + 0 = 0.64
Feature1 = 110[2, 3, 1, 4]0.16 + 0.21 + 0.09 + 0.24 = 0.70
Feature2 = 09[3, 2, 3, 1]58/81 ≈ 0.7160
Feature2 = 111[3, 3, 2, 3]90/121 ≈ 0.7438
Feature3 = 010[2, 3, 3, 2]0.16 + 0.21 + 0.21 + 0.16 = 0.74
Feature3 = 110[4, 2, 2, 2]0.24 + 0.16 + 0.16 + 0.16 = 0.72

Weighted averages, by Definition 7.5:

Gini-Split(Feature1) = (10/20)(0.64) + (10/20)(0.70) = 0.67
Gini-Split(Feature2) = (9/20)(58/81) + (11/20)(90/121) = 362/495 ≈ 0.7313
Gini-Split(Feature3) = (10/20)(0.74) + (10/20)(0.72) = 0.73
answer Split by Feature1, the arg min. The three values are 0.67, 0.7313… and 0.73 for Features 1, 2 and 3 respectively.
Two things this exercise is really testing
  • Feature2 is the one that does not split 10/10. If you average its two child Ginis unweighted you get 0.7299, which would beat Feature3 and change nothing — but on a differently shaped dataset the unweighted average flips the answer outright. Write the (nⱼ/n) factors down.
  • Every split is barely an improvement. The root sits at 0.745 and the best split only reaches 0.67 — against a theoretical maximum of 1 − ¼ = 0.75 for four classes. These features carry almost no information about the class, which is exactly why the tree that eventually gets built cannot classify the training set perfectly.

Build it in the tree tool with the Table 7.4 preset: three binary features give at most 8 distinct feature vectors for 20 rows across 4 classes, so several leaves stay impure and training accuracy tops out well below 100%.
