Why these are worth doing
Where a question has a number in it, that number is produced by the same functions the tools upstairs use — which are themselves checked on every test run against an independent derivation. So the answer you are marked against is one that has been computed rather than typed in, and a mistake in the engine would fail the build before it could mislead you here.
