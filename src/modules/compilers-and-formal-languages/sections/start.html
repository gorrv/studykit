What this file is

One page, and it works offline
Everything is in this single file: the notes, the tools, the search index, the self-test. Nothing is fetched while you read, nothing needs installing, and it opens the same from a hard drive, a USB stick or a plane. Each topic becomes its own entry in the sidebar.

This one is new, so the sidebar is nearly empty. Each topic appears here once its material has been worked through, and nothing is written down until it has been checked.

The four kinds of box

A yellow box
Something worth learning close to word for word — a definition, a rule, or a list that is expected back in full.
A green box
A connection, an intuition, or the reason something is defined the way it is. Understanding rather than memorising.
An orange box
A trap: somewhere the obvious reading is wrong, or a place marks are commonly lost.
A plain box
Context and framing — useful, but not the sort of thing that gets asked directly.

Tools

They run the real thing
A tool is not a picture of a result. It runs the algorithm in front of you, so changing an input changes everything downstream. That makes them useful for the thing a worked example cannot do: checking your own hand-worked answer on an input nobody has given you the answer to.

Every tool has a ↻ Reset tool button at its bottom right, which puts its inputs and its output back to how they started.

Search, theme, printing

Three things in the sidebar
SearchFull text across every topic, including the tools’ prose. Typing filters as you go; Enter jumps to the first hit.
Light / darkTop of the sidebar. It remembers your choice, and follows your system setting the first time you open the page.
Print or PDFCtrl/Cmd+P. The sidebar and the tools are hidden automatically and every topic is laid out in order, so the whole thing prints as one document.
